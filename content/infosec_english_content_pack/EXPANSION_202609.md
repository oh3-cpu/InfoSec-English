## データと音声

- 基本JSON、CSV、`content_pack_combined.json` は従来の基本パックとして維持しています。今回の追加分はこの追加JSONを参照してください。
- 発音練習や日課を指示する既存のプロンプトテンプレートは教材件数に含めていません。
- `scripts/generate-tts.mjs` は追加の単語・フレーズ・Listening・会議各発言・通勤長文をすべてMP3生成対象に含めます。
- GitHub Actionsの既存デプロイ処理が、mainへのマージ後に登録済みAzure Speech設定で音声を生成します。
- ローカルのdry-runは音声生成対象の整合性だけを検証し、Azureには送信せず、MP3やmanifestを変更しません。
- ロールプレイは従来どおりChatGPT練習用プロンプトを使用します。

## 検証コマンド

```sh
node scripts/validate-content-expansion.mjs
npm run generate:tts -- --dry-run
npm run build
```

検証では、各教材の倍増、IDの一意性、新規英文の重複、必須項目、レベル、正解と選択肢、会議の3問構成、コースと長文の対応、長文の最低語数を確認します。
